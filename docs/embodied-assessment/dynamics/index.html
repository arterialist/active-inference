Evidence, encodings & limits

This is a replay of five selected eight-neuron experiments, not a new simulation or an embodied agent. Selection explains mechanisms; it is not a representative acceptance sample. No claim about consciousness follows from these results.

Every tick is retained. No smoothing or activity persistence is used. Plot values are held until the next discrete sample, not interpolated. Transport rates only control how quickly recorded ticks appear. A trial result uses its whole record, including ticks after the cursor. “So far” counts use only ticks through the cursor.

Solid arrows carry information; a terminal bar denotes a negative target synaptic weight. Dashed feedback carries modulator with zero information. Edge width encodes the magnitude of the current target information weight (clamped for legibility), not spike rate or causal importance. A moving packet is not implied. The four-square weight matrix gives exact numeric cue weights.

The diagram is generated from the saved connections. Layout is schematic, not anatomical. Roles label this experimental wiring; the comparator is not a general error detector. Trial schedules and derived classifications never enter the network.

Plots show all samples in their displayed window. Reconstructed membrane, threshold, eligibility, and weight changes are explicitly derived from the raw prior state and current tick. The raw record includes dendritic, presynaptic and retrograde queues.
