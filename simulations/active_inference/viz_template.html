An agent that plans — true active inference

Not a reactive controller. This agent holds an explicit generative model of the world, infers a hidden fact it cannot see by Bayesian belief-updating, and plans by minimising expected free energy over a tree of possible futures. The task is the classic epistemic-foraging T-maze: a reward hides in the left or right arm, and only the cue reveals which. A reward-greedy agent must guess (≈50%). This one walks to the cue to resolve its uncertainty first (epistemic value), then collects the now-certain reward (pragmatic value).

why it chose the cue — planned value of each first move

Planned expected value (−G) after looking ahead. Committing to an arm now is a 50/50 gamble; visiting the cue first, then the correct arm, is worth more — so the planner picks it.

100 episodes per condition, both reward contexts. Turning off either the ability to plan or the epistemic term changes the behaviour in the way the theory predicts — this is what makes it active inference rather than a lucky heuristic.

Why this is true active inference

A generative model, not a policy. The agent is defined by four objects it can reason with: A (how hidden states cause observations), B (how actions change states), C (which observations it prefers — reward good, punishment bad), and D (its prior). It never sees the reward location directly; it infers it.
Perception = free-energy minimisation. After each observation it updates a posterior belief over the hidden context — exact Bayesian updating, which for this discrete model is the minimiser of variational free energy. Watch the belief bar snap from 50/50 to certain the instant it reads the cue.
Action = minimising expected free energy. It scores candidate futures by G = −(pragmatic value) − (epistemic value): pragmatic value pulls toward preferred (rewarding) observations; the epistemic term rewards information gain. The planner searches a tree that branches on anticipated observations, so it discovers that a detour to the cue — worthless in reward — is worth it because the information it yields enables a guaranteed reward next.

Relationship to the spiking organism. The earlier organism in this project is a reactive winner-take-all over hand-set drives — no world model, no lookahead. This is the opposite end: a genuine planner with an explicit model. It is the algorithmic form of active inference (exact discrete inference + expected-free-energy planning), not a spiking network. Implementing the same computation faithfully in PAULA neurons — belief updating as firing-rate dynamics, expected free energy as a neural message-passing scheme — is a much larger research step; this establishes the capability and the correct behaviour first.
