# Real audiovisual research input

`dog-command-source.ogv`: **Labrador barking on command**, Sadie Campbell
(Wikimedia username Nonlinearmind), 13 August 2011.

Source: https://commons.wikimedia.org/wiki/File:Labrador_barking_on_command.theora.ogv

Original media: https://upload.wikimedia.org/wikipedia/commons/d/d0/Labrador_barking_on_command.theora.ogv

License: [Creative Commons Attribution-ShareAlike 3.0 Unported](https://creativecommons.org/licenses/by-sa/3.0/).

`dog-command.mp4` is a resized/transcoded copy, with the original soundtrack.
Extracted frame and auditory feature data are transformations of the same
source, not generated substitutes. These media adaptations retain CC BY-SA 3.0.
No endorsement by the author is implied. Code is separately licensed according
to the repository's terms.

The clip includes a human giving commands. A learned response to this one clip
would not establish dog recognition, bark semantics, or generalization to new
animals, speakers, backgrounds or recordings. The network receives only pixel
and sound measurements; neither this description nor the word “dog” is input.

`cat-chirping-source.webm`: **Cat making noises at the birds outside**, Ali T,
28 March 2009. Original file retained without editing.

Source: https://commons.wikimedia.org/wiki/File:Cat_making_noises_at_the_birds_outside.webm

Original: https://upload.wikimedia.org/wikipedia/commons/1/18/Cat_making_noises_at_the_birds_outside.webm

License: [Creative Commons Attribution 2.0](https://creativecommons.org/licenses/by/2.0/).
The source describes Holly chirping at birds. This is a second audiovisual
recording for content-swapped association controls, not a clean isolated meow
or evidence of category recognition. Extracted measurements are adaptations.
